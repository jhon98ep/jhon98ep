### 👨‍💻 Sobre mí

Ingeniero de Sistemas con más de 4 años desarrollando software en producción, con foco en **backend**.
Diseño y construyo plataformas de punta a punta: arquitectura, modelo de datos, APIs, frontend web y apps móviles.

- 🔭 Hoy desarrollo dos plataformas SaaS en producción: reservas deportivas y domicilios.
- ⚡ He reducido consultas en SQL Server de **15 s a 5 s** y mejorado **30%** el tiempo de respuesta de APIs.
- 🌱 Profundizando en **Go** y arquitecturas orientadas a eventos.
- 💼 Abierto a roles **Backend / Full Stack**, remoto o híbrido.

> *EN — Backend / Full Stack developer (NestJS, Go, PostgreSQL, AWS). Open to remote roles.*
